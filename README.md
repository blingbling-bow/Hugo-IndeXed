# Hugo-IndeXed
收集各类和希沃易 + 系列软件相关的技术细节与使用技巧，旨在帮助人们更透明地了解部分希沃易 + 应用的底层工作原理和技术细节, 类似 Wiki 性质。

站点使用 [VuePress](https://vuepress.vuejs.org/) 与 [vuepress-theme-plume](https://theme-plume.vuejs.press/) 构建。

## 开发

```sh
# 安装依赖
npm install

# 启动开发服务
npm run docs:dev

# 构建生产包
npm run docs:build

# 本地预览构建结果
npm run docs:preview
```
