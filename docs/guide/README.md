# 关于本站

Hugo-IndeXed 是一个类似 Wiki 的知识站点，收集各类与希沃易 + 系列软件相关的技术细节与使用技巧，帮助人们更透明地了解部分希沃易 + 应用的底层工作原理和技术细节。

## 内容范围

- 希沃易 + 系列软件的功能实现方式与可观察行为
- 常见问题的排查思路与使用技巧
- 与这些软件相关的技术资料整理

## 参与贡献

本站内容整理自公开资料与实践经验，欢迎通过 [Issue](https://github.com/blingbling-bow/Hugo-IndeXed/issues) 或 Pull Request 补充与勘误。

::: warning 声明
本站为民间整理站点，内容仅供参考，与希沃官方无关。
:::
